# Шаблон свободного сообщения

`custom-message/` — шаблон для сервиса уведомлений, через который модератор
отправляет свой текст из редактора `notifications-kit` (рассылки и
объявления). Без него редактор в ките выключен: API сервиса принимает только
ключ шаблона и переменные, своего тела у запроса нет.

## Как подключить

Сервис берёт шаблоны из папки, если задан `NOTIFICATION_TEMPLATE_DIR`
(в деплое это ConfigMap; изменения подхватываются без перезапуска). Папку
`custom-message/` целиком положить в эту директорию рядом с остальными
шаблонами. Релиз сервиса не нужен.

Структура — как у шаблонов сервиса: `<ключ>/<канал>/<язык>/`.

| Файл            | Что выводит                                               |
| --------------- | --------------------------------------------------------- |
| `subject.ftl`   | `${subject}` — тема                                       |
| `body.html.ftl` | `${bodyHtml}` — HTML из редактора, для почты — в обёртке  |
| `body.txt.ftl`  | `${bodyText}` — текстовая версия, кит собирает её из HTML |

Каналы: почта, «в приложении» и чат — по папке на канал, так требует схема
сервиса `<ключ>/<канал>/<язык>/`. В чате сервис отправляет `body.html.ftl`
как тело сообщения (для чата это текст или markdown, не HTML), а
`subject.ftl` — как заголовок, поэтому в чат уходит `${bodyText}`. Язык один — `en`: текст пишет человек, а
сервис, не найдя шаблон на языке получателя, берёт язык по умолчанию
(`ludwig.notification.templates.default-locale`, в конфиге сервиса `en`).
Если на стенде язык по умолчанию другой — переименуйте папку `en` в него.
Обращения к получателю нет, поэтому шаблон годится и для объявлений.

## В приложении

В настройках кита: `admin.freeformTemplateKey = 'custom-message'`.

## Безопасность

Сервис не экранирует `bodyHtml` в этом шаблоне (файлы `.ftl`, не `.ftlh`).
Кит перед отправкой оставляет в HTML только разрешённые теги (абзацы,
заголовки, списки, ссылки http/https/mailto, жирный, курсив, цитата, код) и
убирает все атрибуты, кроме `href`. Отправлять могут только роли
`NOTIFICATION_SENDER` / `NOTIFICATION_ANNOUNCER`. В ленте кит показывает HTML
в изолированной рамке без скриптов.
