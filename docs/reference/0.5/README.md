# Эталон 0.5

Снимки демо (`npm run shots`) в разрешении 1440×900 — так должно выглядеть
после подключения 0.5.0. Группа `queue` снята с флагами кабинета по
умолчанию: объявления, показ поверх страницы и колокольчик включены,
входящие и рассылки выключены. Формы модератора сняты со всеми частями.
`queue.mp4` — вся очередь целиком, с анимациями.
