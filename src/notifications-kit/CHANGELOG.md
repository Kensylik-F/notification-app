# Изменения

## 0.4.0

Новый вид всего кита — по макету «Уведомления OneCheck — макет 0.4».

### Объявления поверх страницы

- Всё, что всплывает, живёт в **рабочей области** страницы (элемент с
  атрибутом `data-notifications-anchor` или `anchorRef`), а не у краёв окна:
  стопка — в её правом нижнем углу, полосы — у её верхнего края по центру.
  Шапка сайта и панель AI-агента больше не перекрываются.
- **Стопка, как на телефоне**: спереди новая карточка, сверху выглядывают
  ещё две; «ещё N» — внутри карточки. Клик раскрывает стопку списком с
  шапкой той же ширины: «Объявления · N», «Закрыть все», «Свернуть».
  Карточки переезжают между видами (FLIP), закрытая уезжает вправо,
  остальные смыкаются; «Закрыть все» — каскадом.
- **Кнопка закрытия** — круг 28 px с заливкой и крестиком 12 px (было «×»
  без фона). Наведение, нажатие и фокус видны.
- Полный текст — по клику на карточку или «Подробнее»: окно с «Больше не
  показывать» (или `onOpenAnnouncement` приложения).
- Окно `modal` и полоса `toast` в том же стиле, с анимацией появления и
  ухода.
- **Новое уведомление**: когда счётчик растёт, в углу появляется карточка
  «Новое уведомление» на 8 секунд (наведение — пауза), «Открыть» →
  `onOpenItem`. Отключается `inboxToasts={false}`.
- Нижняя панель форм регистрирует себя, и карточки поднимаются над ней.

### Страница уведомлений — `NotificationCenter` (новое)

- Одна строка вкладок вместо двух уровней: «Входящие N» · «Объявления N»,
  подчёркивание переезжает. «Только непрочитанные» — переключатель справа.
- Слева список (точка, тема, время, первая строка текста), справа —
  выбранное целиком: тема, дата, «Важное», категория, HTML, «Закрыть»,
  «Открыть на отдельной странице». Строки больше не раскрываются на месте.
- «Закрыть» — строка уезжает, открывается следующая.
- «Объявления»: «Активные» и «Закрытые ранее» одним списком, справа — текст
  с «Показывается до …» / «Показывалось до …».
- Уже 720 px — список и текст по очереди, с «К списку».
- Вкладка, выбранное и фильтр — управляемые (для адресной строки).

Удалены `InboxPanel`, `InboxTabs`, `AnnouncementFeed` — их заменяет
`NotificationCenter`. `InboxActions` — «Прочитать все» и «Закрыть все» для
шапки страницы. У `InboxList` вместо раскрытия строк — `selectedId` и
`onSelect`. `InboxItemView` получил вид правой панели и `onOpenSeparately`.

### Колокольчик

- Строки как в списке страницы; клик ведёт в `onOpenItem`.
- «Прочитать все» — ссылкой в шапке списка; счётчик «подпрыгивает», когда
  растёт.

### Рассылка и объявление

- Одна колонка без боковой панели предпросмотра. Секции без номеров:
  «Кому», «Куда» (плитки каналов с иконками и отметкой), «Сообщение»
  («Свой текст / Шаблон сервиса» справа от заголовка), «Параметры»
  (категория и «Когда» рядом; «Дополнительно: класс · приоритет» —
  раскрывается плавно).
- **Нижняя панель закреплена**: «2 получателя × 3 канала = 6 доставок»
  (с правильными окончаниями), «Предпросмотр», «Отправить».
- **Предпросмотр по кнопке** вместо постоянной панели:
  - «В кабинете» — карточка нового уведомления на этой странице, +1 и
    строка в колокольчике, полоса «Ничего не отправлено» над формой;
  - «Письмо» — окно с письмом (тема, от, кому, HTML / текст);
  - «Сообщение в чат» — окно в виде переписки.
  - Объявление показывается там и так, как его увидят (стопка, окно,
    полоса — по категории).
- Редактор: панель в одну строку — «Абзац ▾» (абзац, заголовок, цитата),
  B I U S, списки, ссылка, очистка; справа `</> HTML`.
- Объявление: вид показа подсвечивается сам по введённой категории;
  подтверждение публикации — в окне.
- Неудачная проверка прокручивает к первому отмеченному полю.
- Каналы «В приложении» → «В кабинете».

### Ошибки

- Ответ без описания (шлюз, заглушка, несуществующий адрес) больше не
  превращается в «Не удалось выполнить действие»: показываются код ответа и
  адрес запроса; 404 — «Сервис не знает этот адрес».

### Шаблон свободного сообщения

- `service-templates/custom-message/chat/` — для канала чата. Сервис
  отправляет в чат `body.html.ftl` как тело и `subject.ftl` как заголовок
  (`InternalChatChannel`), поэтому в чат уходит `${bodyText}`.

### Прочее

- `Tabs`, `Switch`, `Button`, `CloseButton`, `Dialog`, `Chip`,
  `formatListTime`, `formatCardTime`, `formatDay`, `plural` — в публичном
  API.
- Палитра по умолчанию — из макета; новые переменные `--nk-*` — в README.
- Всё движение выключается при `prefers-reduced-motion: reduce`.

## 0.3.1

Исправления после проверки 0.3.0:

- Редактор больше не меняет поведение Enter во всём документе (раньше
  включал `defaultParagraphSeparator` глобально — это задевало другие
  редактируемые поля приложения).
- Очистка HTML: список, заголовок или цитата больше не попадают внутрь
  абзаца (`<p><ul>…</ul></p>` — невалидная разметка, почтовые клиенты
  показывали её по-разному); неразрывные пробелы редактора заменяются
  обычными; пустые строки не отправляются, а стёртый текст снова считается
  пустым (возвращается подсказка, срабатывает проверка «напишите текст»).
- Вкладка «HTML»: форма и предпросмотр следуют разметке сразу при вводе, а
  не только при уходе из поля.
- Переключение «Свой текст» ↔ «Шаблон сервиса» не стирает уже введённое.
- Подтверждение публикации на роль: «с ролью «Модераторы»» вместо «с ролью
  «Роли: Модераторы»».
- Группы радиокнопок уникальны на странице: две формы рядом больше не
  мешают друг другу.
- Поле категории закрывает подсказки при уходе фокуса (Tab).
- HTML в рамке подстраивает высоту под содержимое при любых изменениях
  (шрифты, картинки, ширина) и перекрашивается при смене темы.
- В таблице доставок вместо ключа шаблона свободного сообщения — «Свой
  текст».
- Текстовая версия письма не дублирует адрес `mailto:` ссылки.

## 0.3.0

Убрано всё, чего нет в контракте сервиса:

- Каталог шаблонов (`SERVICE_TEMPLATES`, `templateLabels`,
  `variableLabels`) — это были примеры из репозитория сервиса, а не шаблоны
  развёртывания; API списка шаблонов не отдаёт.
- Список «Опубликованные в этой вкладке» — вместо него итог публикации.

Новое:

- **Свой текст в рассылках и объявлениях**: редактор (заголовки, жирный,
  курсив, списки, цитата, ссылки, вкладка HTML) через шаблон свободного
  сообщения `custom-message` (файлы — `service-templates/` репозитория, в
  сервис кладутся без релиза). Настройка `admin.freeformTemplateKey`.
  Второй режим — «Шаблон сервиса»: ключ и переменные парами.
- **Форма рассылки** по шагам; класс и приоритет — в «Дополнительно» с
  пояснениями; свои выпадающие списки вместо системных; предпросмотр
  обновляется сам.
- **HTML в уведомлениях и объявлениях** показывается из коробки, в
  изолированной рамке; «Открыть» в строке ведёт на страницу уведомления.
- **«Закрыть все»** уведомления (`DismissAllButton`, `useDismissAll`) — по
  одному, с подтверждением, прогрессом и остановкой: массового метода в API
  нет.
- **Объявления в углу — стопкой**, как на телефоне; раскрывается по клику,
  есть «Закрыть все».
- **`AnnouncementFeed`** — «Активные» и «Закрытые» (история этого
  браузера; в API истории нет). Проп провайдера `storageScope`.

Изменения API кита: `SendDraft`/`PublishDraft` теперь несут `content:
MessageContent`; `validateSend`/`validatePublish` принимают объект опций;
`buildSendRequest`/`buildPublishRequest` — ключ свободного шаблона вторым
аргументом.

## 0.2.0

Контракт и шаблоны: коммит `0a68e84` сервиса (без изменений).

- **Рассылка** — `NotificationComposer`: шаблон из каталога сервиса или
  свой ключ, данные шаблона, получатели (поиск через `searchRecipients`
  или ID/e-mail, вставка списком), каналы шаблона, категория, класс,
  приоритет, «сразу / запланировать», предпросмотр сервисом, итог с
  доставками, которые обновляются, пока идут. Отправка с
  `Idempotency-Key`, без автоповторов.
- **История доставок** — `DeliveryLog`: фильтры по каналу, шаблону,
  номеру запроса, периоду и статусам, страницы, ход доставки, текст по
  кнопке (аудит, 410), повтор недоставленной, отмена неотправленной.
- **Объявления** — `AnnouncementPublisher`: категория, аудитория «все /
  роль», шаблон для объявлений, срок показа (не больше 90 дней),
  предпросмотр, подтверждение публикации; список опубликованных в этой
  вкладке, ход почтовой рассылки с остановкой, исправление текста.
- Провайдер: проп `admin` — категории, роли, названия шаблонов и полей,
  поиск людей, права по ролям сервиса.
- `core`: каталог шаблонов сервиса (`generated/templates.ts`), логика
  форм — проверки и сборка запросов (`admin.ts`).
- Новые переменные темы: `--nk-color-danger`, `-danger-soft`, `-success`,
  `-warning-soft`, `-warning-border`, `-surface-sunken`, `-surface-input`.

## 0.1.1

- Строка ленты раскрывается на месте: текст, отметка «прочитано»,
  «Скрыть», «Открыть отдельно» (если передан `onOpenItem`). Между строками
  разделители, лента на странице — карточкой.
- Сырой код категории больше не показывается ни в строке, ни на странице
  уведомления: подпись из `describeItem` или «Уведомление».
- `NotificationBell`: список выводится в `<body>`; `anchorRef` выравнивает
  его по краю шапки, `anchorInset` — отступ. Раскрытие строк работает и в
  колокольчике.
- `InboxItemView`: «Скрыть» под текстом, `showSubject`;
  `useInboxItemTitle(id)` для шапки страницы.
- Лента защищена от сервера, который игнорирует `$skip`/`$top`: строки не
  дублируются, «Показать ещё» не бесконечна. Тема строки берётся по тому
  id, который запрашивали.
